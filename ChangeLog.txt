PyAdhan v2.11.2.0:-

[Features]
-Switched prayer times caching to single-day caching with fresh fetch on every run and offline cache fallback.

[Bug Fixes]
-Fixed audio output handling to dynamically recheck configured devices on each adhan playback and use the system default temporarily if disconnected without overwriting saved settings.
-Fixed an issue where clicking the minimize button could maximize the window.
-Fixed midnight day-rollover prayer time updates.

[Minor]
-Added "Stop Adhan" button that's usable if there's a running adhan.
